Usage notes
============

English
-------

This system is an open system. It has been optimized for use on ARM handheld devices.

There are two x86_64-to-ARM converters: BOX64 and FEXEmu. For Decky Loader to work, you must install ONE of these converters before installing Decky Loader.

If you are not sure which one to install, I recommend the easiest option: BOX64 is quick to install, takes very little space, and is minimally invasive. That is enough for Decky Loader to work well.

BOX64 does not affect Steam. If you use an x86_64 Proton, Steam itself installs and uses its own FEXCore. ARM Proton builds use their own FEXCore in the same way.
